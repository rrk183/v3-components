ضوابط أمان API

كما هو الحال مع جميع خدماتنا الأخرى، تستوفي بروتوكولات الخدمات المصرفية عبر API أعلى معايير الأمان لتمنحكم راحة بال تامة. وتشمل:

أمان طبقة النقل

تُجرى استدعاءات API عبر HTTPS باستخدام أمان طبقة النقل (mTLS 1.2).

المصادقة

بصفتكم عميل API، يجب أن تقدموا مفتاحاً وكلمة سر وشهادة خاصة بكم وفقاً لبروتوكول OAuth 2.0 المعتمد في القطاع.

رمز JWT

تحمل استدعاءات API رمز JWT صالحاً (JSON Web Token) موقّعاً رقمياً من جهة إصدار رموز معروفة. ويجب أن يكون رمز JWT صالحاً وأن يحدد هوية المستخدم أو النظام الذي يستخدم API.

التفويض

يجب تسجيل عملاء API في محرك الخدمات المصرفية عبر API لاستخدام الواجهات بصلاحيات وصول مناسبة إلى البنك والموارد الأخرى.

أمان طبقة الرسائل

يجب توقيع معاملات طلب API وحمولته رقمياً باستخدام مفتاح خاص آمن ومخصص للعميل.
