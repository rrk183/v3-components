# Cards — Tiles, head aside

`cards-tiles-aside` · Cards · variant of **Cards — Tiles** — see
[cards-tiles.md](cards-tiles.md). The `is-head-aside` layout modifier puts
the headline + lead in the left column (vertically centred) and the 2-up
tile GRID on the right; the Columns control drives is-cols-N. For the
scrolling version use `cards-tiles-aside-carousel`.
