# Tabs — Directory

`tabs-directory` · Tabs · composition of **[[tabs-underline]]** + **[[cards]]**

The pills-in-content directory (replaces tabs-pills-grid): underline rail over a `cmp-cards.is-cols-auto` grid of `card-panel.is-flat` tiles, one short service name each (`--card-pad` sets the pill inset). For tabs holding MANY short items; panels swipe on phones. Zero CSS of its own.

## Options
- **Described tiles** (2026-10-13): each tile may hold its title as an `h3` plus one `type-body-sm ink-mute` line (all tiles or none). Tab labels keep the ink pair: `ink-primary` on the active tab, `ink-mute` on the rest.
