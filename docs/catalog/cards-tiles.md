## Head-aside variants (2026-09-02)
`cards-tiles-aside` — the same tiles with the block headline + lead in a
left column (the `is-head-aside` layout modifier, vertically centred) and
the tile GRID on the right. `cards-tiles-aside-carousel` swaps the grid
for the shared carousel track, bleeding to the viewport edge. The modifier
owns the split; both take the Columns control.
