# cards-tombstones

`cards-tombstones` · Cards · composition of **[[cards]]**

Tombstones composition of [[cards]] — flat deal cards (`card-panel is-flat`): logo well, amount (type-h5 type-navy), detail lines, border-t hairline, country · date meta-dot foot, optional `badge badge-ok badge-sm` ESG pill; replaces tombstone-grid / key-transactions; see the family dossier.

## Options
- **Header optional on library pages** (2026-10-12): on a dedicated tombstone library page, the grid may run without a section header; the page title above does that job.
- **Text-only tombstones:** cards without a logo well, on unpainted (`surface-clear` or no surface) panels.
- **Footer see-all button:** one centred button under the grid instead of a header link.
- **Foot optional:** drop the meta-dot foot when a deal has no date or place to show.
- **Two header links:** up to two stacked `btn-text is-arrow` links in the header right column (e.g. two tombstone libraries).
- **Date-only foot:** the meta-dot foot may hold the date alone when no place applies.
- **Count / ESG legend row optional:** drop it when no deal is ESG.
- **Header link:** a "See all" `sh-action` link in a split header (Section Header options).
- **Foot line content:** `meta-dot` foot carries place (country or listing venue) and date.
