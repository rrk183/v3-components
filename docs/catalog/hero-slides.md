# Hero — Carousel

`hero-slides` · Heroes · composition of **[[hero]]**

The one hero in carousel mode: `data-carousel` track of hero stages — the SAME shared core as cards (arrows, numbered dots, autoplay, play/pause). Each slide authors its OWN media and `.ov` overlays (slide 1 gradient-left, slide 2 gradient-bottom, slide 3 radial + blue tint in the demo). Nav = numbered pagination with the timed underline (`--hero-auto` mirrors `data-autoplay`) + frosted `crl-btn` circles at the end — the estate pattern Hakan picked.
