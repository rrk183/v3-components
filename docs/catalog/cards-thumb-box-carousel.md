## When to use
Reach for the carousel when there are more cards than fit in one row and
horizontal browsing suits the content. For a fixed small set, use the Grid.

## Everything else
Slots, layouts, controls and drift cautions are the same as the Grid — see
[[cards-thumb-box]]. Authoring: read `blocks/cards-thumb-box-carousel.html`,
change CONTENT only.
