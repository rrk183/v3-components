# Cards — List

`cards-list` · Cards · composition of **[[cards]]** on the `is-list` layout

The LISTING (Hakan 2026-09-01: a separate component, not part of the accordion): `is-list` is the 4th cmp-cards layout mode — single column of hairline rows, row-direction cards. A row = `media-frame` square thumb at the start + a title + subdescription `ds-stack` + a trailing action (the layout pushes the last child to the end). Rows navigate; for collapsing rows use [[acc]].
